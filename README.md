✦ Aster — JEE Study Planner

A personal study management platform designed to make JEE Main and JEE Advanced preparation more organized, productive, and engaging.

Aster is a student-focused study tracker built to help aspirants manage their daily tasks, monitor syllabus completion, maintain consistency, and track their learning progress.

✨ Features

- 📚 Syllabus Tracker — Organize and monitor chapter-wise progress across Physics, Chemistry, and Mathematics.
- ✅ Task Management — Create and manage daily study goals.
- ⚡ XP & Rewards — Earn experience points by completing study tasks.
- 🪙 Coins System — Track rewards and maintain motivation.
- 🔥 Study Streaks — Encourage consistency through daily study tracking.
- 📊 Progress Tracking — Keep track of your preparation journey.
- 📱 Responsive Interface — Designed with mobile usability in mind.
- 💾 Data Persistence — Store supported progress locally using browser storage.

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Firebase (where configured)

🎯 Project Goal

The goal of Aster is to combine productivity, organization, and gamification into one platform specifically designed for competitive examination preparation.

Instead of relying on multiple apps to manage tasks, track progress, and organize a syllabus, Aster aims to bring these tools together in one place.

🚀 Getting Started

You can access the deployed website through GitHub Pages once deployment is enabled.

To run the project locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a modern web browser.
